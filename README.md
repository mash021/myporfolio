# Mike Sharifi — 3D Interactive Portfolio

A modern, immersive personal portfolio built with cutting-edge web technologies. Featuring real-time 3D graphics, smooth animations, and a fully responsive design — crafted to showcase advanced frontend engineering skills.

**Live Demo**: [alisharifi-portfolio.com](https://alisharifi-portfolio.com)

---

##  Features

- **3D Interactive UI** — Built with Three.js & React Three Fiber
- **Smooth Animations** — Powered by Framer Motion
- **Dark / Light Mode** — Dynamic theme switching
- **Fully Responsive** — Mobile-first with Tailwind CSS
- **Type-Safe Codebase** — Written in TypeScript
- **Contact Form** — Integrated with EmailJS
- **SEO Optimized** — Meta tags, Open Graph & structured data
- **95+ Lighthouse Score** — Optimized performance across all metrics

---

##  Tech Stack

| Layer | Technologies |
|-------|-------------|
| Framework | Next.js 14 (App Router) |
| 3D Graphics | Three.js, React Three Fiber |
| Animations | Framer Motion, Lottie |
| Styling | Tailwind CSS |
| Language | TypeScript |
| Email | EmailJS |
| Deployment | Vercel |

##  Getting Started

```bash
# Clone the repo
git clone https://github.com/mash021/myporfolio.git
cd myporfolio

# Install dependencies
npm install

# Run development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

---

##  Scripts

```bash
npm run dev      # Start dev server
npm run build    # Build for production
npm run start    # Start production server
npm run lint     # Run ESLint
```

##  Deployment

Deployed on **Vercel** — the recommended platform for Next.js apps.

1. Push your code to GitHub
2. Import the repo at [vercel.com](https://vercel.com)
3. Vercel auto-detects Next.js and deploys instantly
